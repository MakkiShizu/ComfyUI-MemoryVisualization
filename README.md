# ComfyUI 内存可视化 汉化版本

ComfyUI 的实时显存（VRAM）与内存监控面板。fork自[kijai/ComfyUI-MemoryVisualization](https://github.com/kijai/ComfyUI-MemoryVisualization)

启用 [aimdo](https://github.com/Comfy-Org/comfy-aimdo/) 时，还会显示每个模型的页面级驻留热力图以及水印控制。

<https://github.com/user-attachments/assets/0d212946-1309-468d-ad0f-178ea26ba257>

## 安装

将本项目克隆到你的 `custom_nodes` 目录：

```
git clone https://github.com/MakkiShizu/ComfyUI-MemoryVisualization ComfyUI/custom_nodes/ComfyUI-MemoryVisualization
```

## 额外添加功能：重置所有设置

在面板任意位置右键打开设置菜单 → 点击 重置所有设置 → 确认 → 页面刷新后所有设置回到默认。
